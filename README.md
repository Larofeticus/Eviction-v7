# Eviction: V7

A server plugin for [Mindustry](https://github.com/Anuken/Mindustry) (v7, build 146): a free-for-all hex PvP game mode.

> **Archived.** This repository is a historical snapshot, provided as-is. It is not maintained or supported, and it may no longer build or run against current versions of Mindustry.

I will keep the discord server around, and probably post things there about other hobby projects of mine, there.

[Discord](https://discord.gg/GdnsrmKKAM) 

## About

When I first started playing Mindustry I played on a hex server named Assimilation, which was at the time operated by a player named Recessive. That server shut down, so I decided to write a version myself, including some changes I had always wanted. I named it Eviction.

The Eviction server opened on September 27, 2021.

Since then I've gotten married and gained two daughters. I stopped being able to play in The Good Games, and my sense of what the game needs has became outdated. 

My stance on the source code has always been: "I'll release the source code when I'm no longer operating the servers." That time is coming.
